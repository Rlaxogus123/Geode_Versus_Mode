# 음악 건너뛰기 검증

테스트 폴더의 목적, 파일 구성, 검증 원리와 범위는 [기술 설명](OVERVIEW.md)을 참고하세요.

## 자동 테스트

Geode SDK나 Geometry Dash 없이 준비 버튼의 상태 전환을 검증할 수 있습니다.

```sh
cmake -S tests -B build-tests
cmake --build build-tests --config Release
ctest --test-dir build-tests -C Release --output-on-failure
```

호스트/참가자 양쪽에서 다운로드 중 준비 버튼 비활성, 따로 둔 건너뛰기 버튼의 표시 조건과
보인 뒤 1초 대기, 캐시 완료 후 준비, 준비 해제, 경기 시작 및 서버 응답 대기 중 비활성 상태를 확인합니다.
네트워크 취소와 게임 화면은 이 테스트에서 실행하지 않습니다.

## 모드 빌드

`mod.json`의 Geode 5.7.1 / GD 2.2081 및 기존 빌드 워크플로의 바인딩 커밋
`7f6c2a75742856de88dad354e576dcff8a28e881`을 사용합니다.
`GEODE_SDK`와 `GEODE_BINDINGS_REPO_PATH`를 해당 경로로 설정한 뒤 빌드합니다.
Windows에서는 Visual Studio 개발자 명령 프롬프트와 Ninja를 사용하며, 검증 빌드가 게임에
자동 설치되지 않도록 다음 옵션을 지정합니다.

```sh
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DGEODE_DONT_INSTALL_MODS=ON -DSKIP_BUILDING_CODEGEN=OFF
cmake -E make_directory build/Release
cmake --build build --parallel 3
```

빌드 결과에는 현재 플랫폼의 바이너리와 `resources/`의 이미지/사운드가 포함됩니다.
게임 테스트 전에 기존 Versus 패키지를 모드 폴더 밖에 백업하고 게임을 종료한 상태에서
테스트 패키지로 교체합니다. 기존 태그 기반 배포 워크플로는 이 기능의 검증용으로 실행하지 않습니다.

## 게임 내 확인 항목

아래 항목은 자동 테스트의 통과 여부와 별도로 확인해야 합니다.

- Classic 1v1의 호스트/참가자, Group의 호스트/참가자, Ranked의 각 컵에서
  아직 받지 않은 커스텀 노래와 효과음이 있는 맵을 선택합니다.
- 다운로드가 시작되면 준비 버튼(Ranked는 GET READY)은 비활성 그대로이고, `음악 건너뛰기`는 따로 둔
  파란 버튼으로 나타나는지 확인합니다(1v1: 가운데 줄 Downloading 옆, Group: 다운로드 진행 문구 옆,
  Ranked Season 2: 매치 카드의 LDM 오른쪽). 나타난 뒤 1초 동안은 눌리지 않아야 합니다.
  패치 노트/안내 팝업의 언어를 English로 바꾼 뒤에는 `Skip Music`이어야 합니다.
  작은 가로 화면에서도 글자가 잘리거나 이웃 버튼과 겹치지 않아야 합니다.
- 레벨 데이터를 받기 전에 누르면 레벨 다운로드는 계속되고, 데이터 검증 전에는 준비되지
  않아야 합니다. 유효한 레벨을 받으면 기존 준비 요청이 전송되어야 합니다.
- 음악 또는 효과음을 받는 도중 누르면 Versus가 시작한 해당 전송이 취소되고 추가 오디오
  요청이 없어야 합니다. 노래 정보 응답이 늦게 도착해도 노래 전송을 시작하지 않아야 합니다.
- 빠르게 여러 번 누르거나 다운로드 완료 직전에 눌러도 준비 상태가 다시 해제되지 않아야 합니다.
- 경기를 시작했을 때 로딩 화면에서 건너뛴 오디오를 다시 받지 않고 게임이 시작되어야 합니다.
  없는 오디오는 재생되지 않으며, 기존에 저장된 노래/효과음은 삭제하거나 음소거하지 않습니다.
- 맵 변경, 같은 맵을 다시 뽑는 리롤, 방 이동/재입장 후에는 이전 건너뛰기 선택이 남지 않아야 합니다.
  건너뛰기를 누른 뒤 방을 나가거나 맵을 바꾸어도 이전 콜백이 새 맵을 자동 준비시키면 안 됩니다.
- 삭제된 맵, 빈 레벨 데이터, Platformer는 건너뛰기를 눌러도 기존 오류 처리를 유지해야 합니다.
- 건너뛰기를 누르지 않은 일반 다운로드, 이미 받은 오디오, 여러 곡/SFX를 사용하는 레벨,
  Ranked의 `Always Download Song` 설정 켜짐/꺼짐도 기존 동작을 유지해야 합니다.
- 수동 건너뛰기가 노래 제공자 오류로 신고되거나 Ranked의 자동 리롤/패널티를 유발하지 않아야 합니다.
